# ALVAR — Moda Masculina

Protótipo demonstrativo Or7.dev.

## Desenvolvimento

```bash
npm ci
npm run dev
```

## Publicação

Configure o repositório `moda-masculina-demo` em Settings > Pages > GitHub Actions. O workflow publica a branch `main` automaticamente.

Site: https://lorenzo-or7.github.io/moda-masculina-demo/

As fotografias são servidas pelo Unsplash e dependem de conexão com a internet.
